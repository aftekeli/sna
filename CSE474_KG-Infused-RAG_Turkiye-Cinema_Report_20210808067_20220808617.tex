\section{Executive Summary}

This project implements a \textbf{KG-Infused Retrieval-Augmented Generation} (RAG) system for multi-hop question answering in the Türkiye cinema domain. The system starts from Wikidata5M, identifies Türkiye-related cinema entities, exports a Neo4j-ready subgraph, builds a verified 50-question multi-hop QA benchmark, and evaluates four answering strategies: \emph{No Retrieval}, \emph{Vanilla RAG}, \emph{Vanilla Query Expansion}, and \emph{KG-Infused RAG}.

The final evaluation shows full coverage for all four methods: 50/50 successful outputs and zero ERROR predictions. \textbf{KG-Infused RAG} is the strongest method, reaching \textbf{98.0\%} accuracy, exact match, and F1, with \textbf{97.0\%} retrieval recall.

\section{Phase 1 - Dataset Exploration \& Türkiye Entity Detection}

The exploration stage identifies \texttt{Q43} as the Türkiye root entity in Wikidata5M. Key findings:

\begin{itemize}
\item Direct Q43-connected triples: \textbf{22{,}103} - incoming: 21{,}885 / outgoing: 219.
\item Türkiye-origin subjects: \textbf{759}.
\item Top cinema relations: \texttt{P495} (country of origin), \texttt{P27} (citizenship), \texttt{P19} (place of birth), \texttt{P69} (educated at).
\item Cinema density: \textbf{270} Turkish films and \textbf{359} cinema-domain persons.
\item City/place evidence appears through birth-place, country, and education-location paths used later in the QA dataset.
\end{itemize}

\section{Phase 4 \& 5 - KG-Infused RAG Pipeline \& Evaluation}

The pipeline consists of three sequential modules:

\begin{itemize}
\item \textbf{Module 1 - KG-Guided Spreading Activation:} seed entity selection, iterative 1-hop expansion, LLM triple selection, and activation memory.
\item \textbf{Module 2 - KG-Based Query Expansion:} KG subgraph summary is used to generate an expanded query, followed by dual-query corpus retrieval.
\item \textbf{Module 3 - KG-Augmented Answer Generation:} passage note and KG facts are combined to form a fact-enhanced answer context.
\end{itemize}

\section{Conclusions \& Recommendations}

This project demonstrates that KG-Infused RAG substantially outperforms all baselines on multi-hop question answering over the Türkiye Cinema domain.

\begin{itemize}
\item \textbf{KG grounding is critical:} the 90-point EM gap between No Retrieval (0.08) and KG-Infused RAG (0.98) measures the value of structured knowledge for multi-hop reasoning.
\item \textbf{LLM hallucination} is the dominant failure mode (3/5 failures), addressable through single-entity output constraints and structured prompt templates.
\item \textbf{KG data deficiency} accounts for 1/5 failures; augmenting Wikidata5M with live Wikidata API or DBpedia is the highest-impact infrastructure fix.
\item \textbf{Spreading activation} successfully navigates 2-hop and 3-hop reasoning chains while maintaining full trace coverage (50/50).
\item \textbf{Future work:} integrate R-GAT graph attention networks for learned entity weighting during activation.
\end{itemize}
